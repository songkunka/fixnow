# FixNow Brand CI — Editable Assets

## Main editable files
- `FixNow_Brand_CI_Editable.pptx`: five-slide PowerPoint. Text, palette swatches, dividers, logo parts, and service icons are native editable objects. Photo/mockup assets are separate selectable image objects.
- `FixNow_Brand_CI_Editable.svg`: one large SVG brand board. Text and vector shapes are distinct named SVG elements/groups; each photo/mockup is an independent embedded image object. Open in Adobe Illustrator, Inkscape, or import into Figma.

## Folders
- `logos/`: primary horizontal logo, reversed logo, symbol, and app icon as SVG.
- `icons/`: seven separate line-icon SVGs (battery, tire, tow truck, engine, location, booking, safety).
- `photos/`: individual photo/mockup crops from the supplied board; replace these files with higher-resolution originals if available.

## Important editing note
The source board is a flattened image. Logo elements, typography samples, color swatches, layout and service icons have been rebuilt as editable vector/text objects. The 3D mascot renderings, uniform/vehicle mockups, mobile mockup and promotional image are retained as separate raster images because their internal pixels cannot be converted into accurate editable shapes automatically.
